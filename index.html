📚 핵심 이론 정리

수능 수학 킬러 문항에서 자주 출제되는 절댓값 삼각함수와 직선의 교점 유형을 체계적으로 정리합니다.

1

절댓값 사인 함수의 기본 구조

y = |A · sin(B(x − C)) + D|
📌 A (진폭)
그래프의 최대·최솟값 범위를 결정. |A|sin 형태에서 최댓값은 |A|+|D|, 최솟값은 D에 따라 달라짐.
📌 B (주기 계수)
주기 = 2π/B. B가 클수록 주기가 짧아져 단위 구간 내 교점 수가 늘어남.
📌 C (위상이동)
그래프를 x방향으로 C만큼 평행이동. C>0이면 오른쪽, C<0이면 왼쪽.
📌 D (수직이동 / 폴딩포인트)
|sin + D| 구조에서 D = 0이면 일반 |sin|. |D|>1이면 절댓값 꺾임이 사라짐.
🔑 킬러 포인트: D값과 교점 개수의 관계

y = |sin(x) + D|에서:

  • |D| > 1 (예: D = 1.5): sin(x)+D > 0 항상 → 절댓값 기호 제거 가능. 단조적인 파형
  • D = 0: 반주기마다 x축을 "반사"하여 솟구치는 형태 → 교점 수 최대
  • D = −1: sin(x)−1 ≤ 0 (sin=1일 때만 0) → 거의 0에 붙어있는 형태
2

절댓값 코사인 함수의 특징

y = |A · cos(B(x − C)) + D|
📌 사인과의 차이
cos(x)=sin(x+π/2). x=0에서 cos(0)=1로 시작하므로 초기 교점 분석이 달라짐.
📌 x=0에서의 초기값
|cos(0)|=1, |sin(0)|=0. x=0 부근 직선과의 교점은 코사인이 더 많을 수 있음.
📌 우함수 특성
cos(x)는 우함수. C=0이면 y축에 대칭. 절댓값 적용 후 π-주기 우함수.
📌 수능 출제 패턴
구간 [0, kπ]에서 교점의 개수 = n이 되도록 m, n을 구하는 유형. C 조작으로 대칭축 이동.
🔑 킬러 포인트: 코사인의 극값 위치

y = |cos(B·x)|의 최대값 위치: x = 0, π/B, 2π/B, ...

y = |cos(B·x)|의 최솟값(0) 위치: x = π/(2B), 3π/(2B), ...

  • 직선이 최대값 위를 지나면 그 주기에서 교점 없음
  • 직선이 최대값 위치에서 접하면 교점 1개 (접점)
  • 직선이 최솟값과 최댓값 사이를 지나면 교점 2개
3

절댓값 탄젠트 함수의 분석

y = |A · tan(B(x − C)) + D|
📌 주기와 점근선
tan의 주기 = π/B. 점근선: x = C + π/(2B) + nπ/B. 절댓값 적용 시 주기 π/(2B)로 단축!
📌 절댓값의 효과
|tan(x)|는 음의 값이 위로 반사. 주기 π → π/2. 각 반주기에서 0→+∞ 패턴 반복.
📌 직선과의 교점
|tan|은 단조증가 구간별로 직선과 최대 1개. 기울기가 너무 크면 교점 없음.
📌 D값의 역할
D≠0이면 |tan+D|에서 꺾이는 위치 이동. D<0이면 아래쪽 반사로 새 극소값 생성.
🔑 킬러 포인트: 탄젠트 점근선 구간 분석

점근선 사이의 각 구간에서:

  • tan: −∞→0→+∞ → |tan|: +∞→0→+∞ (V자 형태)
  • 직선 y=mx+n이 각 V자와 만나는 횟수 분석
  • 주의: 점근선 근처에서 교점은 항상 1개 이상
★

교점 개수 분석 전략 (수능 실전)

STEP 1
주기 확인 & 구간 분할
B값으로 주기를 계산하고, 주어진 x 구간에 몇 개의 주기가 포함되는지 파악. 각 주기별로 독립 분석.
STEP 2
극값(최대/최소) 위치 계산
각 주기에서 극대·극소값과 그 x좌표 파악. C(위상이동) 고려하여 정확한 x값 산출.
STEP 3
D값으로 절댓값 꺾임 분석
f(x)+D=0이 되는 지점이 꺾임점. 꺾임점에서 직선과의 관계 분석.
STEP 4
직선과 각 호(arc)의 교점 수 세기
각 단조 구간에서 직선이 삼각함수 그래프를 몇 번 가로지르는지 분석.
STEP 5
경계 조건 확인
x=0 또는 구간 끝점에서의 교점 여부. 절댓값 꺾임점이 직선 위/아래에 있는지 판별.

사인 킬러
문제 1
함수 f(x) = |2sin(2(x−1))|의 그래프와 직선 y = mx + n의 교점의 개수가 정확히 5개가 되도록 하는 m, n의 조건을 탐구하시오. (단, 0 ≤ x ≤ 10)
💡 풀이 접근법
  1. A=2, B=2, C=1, D=0 → 주기 = π ≈ 3.14
  2. x∈[0,10]에 약 3.18 주기 포함 → 최대 교점 6~7개
  3. 5개가 되려면 마지막 주기에서 교점 1개 조건 필요
  4. m ≈ 0.3~0.5, n ≈ 0.5~1.0 구간 탐구
▶ 핵심 조건
x=1+π/4≈1.785에서 최대값 2. 직선이 이 점을 접선처럼 통과 → 해당 봉우리에서 교점 1개.
사인 준킬러
문제 2
함수 f(x) = |sin(x) − 0.5|의 그래프와 직선 y = 0.1x + 0.3의 교점의 개수를 구하고, D값을 변화시키면서 교점 수 변화를 관찰하시오.
💡 핵심 개념: 폴딩포인트 (D값)
  1. D=−0.5이면 sin(x)=0.5일 때 꺾임 발생
  2. D=0 → D=−1로 변화시키며 꺾임 위치와 교점 수 변화 관찰
  3. D=−1에 가까울수록 그래프가 평탄해짐
▶ 관찰 포인트
D=−0.5에서 교점 약 3~4개. D→−1이면 그래프 평탄화로 교점 수 감소.
사인 킬러
문제 3 (기출 유형)
실수 t에 대하여 f(x) = |sin(2x) + t|의 그래프와 직선 y = (1/4)x의 교점의 개수를 g(t)라 할 때, g(t)가 불연속인 t의 값의 개수를 구하시오.
💡 풀이 전략
  1. t=D로 설정, D를 −1~1 사이에서 조금씩 변경
  2. 교점 수가 갑자기 바뀌는 t값 탐색
  3. t=0, ±1이 불연속 후보
▶ 힌트
D=−1: |sin(2x)−1|=0인 점에서 직선과 접하면 불연속. t∈{−1,0,1} 각각 확인.
코사인 준킬러
문제 4
함수 f(x) = |cos(x) + 0.5|의 그래프와 직선 y = mx + 0.5 (m > 0)의 교점의 개수가 홀수가 되도록 하는 m의 범위를 탐구하시오. (0 ≤ x ≤ 3π)
💡 풀이 접근법
  1. D=0.5 → cos(x)+0.5=0 → x=2π/3, 4π/3, ...에서 꺾임
  2. 꺾임점에서 직선이 접하면 교점 수 홀수 가능
  3. m을 0.05에서 천천히 증가시키며 교점 수 변화 관찰
▶ 관찰 포인트
m이 매우 작으면 교점 6개(짝수), m 증가 시 마지막 주기에서 5개(홀수) 구간 존재. m≈0.15~0.25 집중 탐구.
코사인 킬러
문제 5
함수 f(x) = |1.5·cos(1.5x) − 0.5|의 그래프와 직선 y = mx + n의 교점의 개수가 정확히 7개가 되는 (m, n) 쌍을 시뮬레이터로 구하시오. (0 ≤ x ≤ 10)
💡 풀이 전략
  1. B=1.5 → 주기 ≈ 4.19. x∈[0,10]에서 약 2.39 주기
  2. D=−0.5 → cos(1.5x)=1/3일 때 꺾임
  3. 최댓값 = 2.0. 직선이 완만하게 증가해야 7개 달성 가능
▶ 탐구 영역
m≈0.2~0.3, n≈0~0.5 구간 탐구. 7개는 마지막 반주기에서 직선이 한 번 더 만나는 특수 기울기 조건.
코사인 킬러
문제 6 (기출 유형)
함수 f(x) = |cos(2(x−1))|의 그래프와 직선 y = k (상수)의 교점의 개수가 짝수인 양의 정수 중 최댓값 k를 구하시오.
💡 풀이 접근법
  1. B=2, C=1 → 주기 π/2≈1.57. x=1에서 cos(0)=1 시작
  2. 수평선 y=k (m=0, n=k)와의 교점 분석
  3. k=1: cos=1인 점에서만 접함 → 홀수
  4. k=0.5: 각 주기에서 2개 교점 → 짝수
▶ 관찰 포인트
m=0으로 설정하고 n(=k)을 조절. n=1에서 홀수, n=0.9에서 짝수 확인.
탄젠트 준킬러
문제 7
함수 f(x) = |tan(x)|의 그래프와 직선 y = mx + n이 0 ≤ x ≤ 3π에서 갖는 교점의 개수를 m값에 따라 분류하시오. (단, m > 0)
💡 핵심 개념
  1. |tan(x)|의 주기=π/2. x∈[0,3π]에서 6개의 "V 패턴"
  2. 각 V: 0에서 시작 → +∞로 발산 (점근선에서)
  3. m이 클수록 각 V와의 교점 수 감소
  4. m이 매우 작으면 총 최대 12개 가능
▶ 분류 기준
m<1: 각 구간에서 교점 2개 가능. m=1: 일부 감소. m>1: 후반 구간에서 교점 없음.
탄젠트 킬러
문제 8
함수 f(x) = |tan(2x) + 0.5|의 그래프와 직선 y = 0.5x + n의 교점의 개수가 정확히 4개가 되는 n의 범위를 구하시오. (0 ≤ x ≤ 4)
💡 풀이 전략
  1. B=2 → |tan(2x)|의 주기=π/4≈0.785. x∈[0,4]에서 약 5개 주기
  2. D=0.5 → tan(2x)=−0.5일 때 꺾임
  3. n 슬라이더를 −1에서 2까지 조절하며 교점=4 범위 탐색
▶ 탐구 영역
n≈0.5~1.5 구간에서 교점 4개 가능. n이 너무 크면 초반 주기에서만 교점.
탄젠트 킬러
문제 9 (기출 유형)
함수 f(x) = |tan(x − π/4)|의 그래프와 직선 y = (1/π)x의 교점의 개수를 구하고, 교점의 x좌표의 합 S에 대하여 ⌊S⌋를 구하시오. (0 ≤ x ≤ 3π)
💡 풀이 접근법
  1. C=π/4≈0.785. 점근선: x=3π/4+nπ
  2. 1/π≈0.318. 이 기울기의 직선과 각 V패턴 분석
  3. 시뮬레이터에서 C=0.785, m≈0.318로 근사
▶ 시뮬레이터 설정
C≈0.8, m≈0.32, n=0. 교점 좌표 합산 후 내림. 정확한 값은 이론적 분석 필요.
